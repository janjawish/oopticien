# O’Opticien

Site vitrine d’O’Opticien, opticien indépendant à Mantes-la-Jolie.

## Développement

```bash
pnpm install
pnpm dev
```

## Contrôles

```bash
pnpm check
```

Le build produit un export statique dans `out/`, déployé sur GitHub Pages par le workflow `deploy-pages.yml`.

## Contenu

Les coordonnées, horaires, services et marques proviennent du site historique d’O’Opticien. Les données juridiques ont été recoupées avec le BODACC et les registres publics. Les photographies de montures sont issues des médias déjà publiés par la boutique.
